# FlipERP brand assets

Official FlipERP logo, "Page flip" design (November 2026). Use these files only; do not recreate or restyle the logo.

## Folders
| Folder | What | Use |
|---|---|---|
| `logo/` | Horizontal and stacked logos (SVG + PNG) | `fliperp-logo-horizontal` on light backgrounds, `-white` on dark/navy, `-navy` for one-colour print, `stacked` for square spaces (login, splash) |
| `icon/` | The icon mark alone | Sidebar collapsed state, small headers, avatars. `fliperp-app-icon-1024` for app stores / PWA |
| `favicon/` | `favicon.ico`, `favicon.svg`, PNG sizes 16–512, `apple-touch-icon.png`, `site.webmanifest` | Browser tab, bookmarks, home-screen install |
| `loader/` | Official loader | `fliperp-loader.svg` (animated, preferred: crisp and light). GIF versions for places SVG animation can't run (emails, some PDFs, legacy views): `fliperp-loader.gif` (white bg), `-dark.gif` (navy bg), `-transparent.gif`, `-64.gif` (small) |
| `social/` | 1080 × 1080 profile picture | Social media and WhatsApp profile |

## Colours
| Name | Hex | Use |
|---|---|---|
| Navy | `#12203C` | "Flip" wordmark, text, dark backgrounds |
| Blue | `#1F6FDC` | Icon tile, "ERP", primary brand colour |
| Deep blue | `#0F4BA8` | Shadows, hover, accents |
| Light blue | `#33C2F0` | Page-fold highlight, accents |

## Typeface
Inter: Extra Bold (logo wordmark), Semi Bold (headings, tagline), Regular (body).

## Rules
- Keep clear space around the logo equal to the height of the "F" in the icon.
- Minimum size: horizontal logo 120 px wide; icon 16 px.
- Don't stretch, recolour, add shadows or effects, or put the colour logo on busy photos (use the white version on a dark overlay).
